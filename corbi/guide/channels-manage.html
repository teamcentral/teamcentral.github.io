Managing Channels ​

Once you've created channels, you can review, edit, and remove them from one place.

Open your channels ​

Go to Settings → Manage Channels. You'll see a list of every channel you've set up.

Edit a channel ​

Select a channel to open it for editing. You can change any of its settings:

  • Channel Name
  • Channel Scope (Broad or Narrow)
  • Category
  • Channel Tags

These are the same fields you set when creating a channel — see About Channels for what each one does. Make your changes and select Save, or Cancel to discard them.

Changing the category resets your tags

Tags belong to a category. If you switch a channel to a different category, the tags from the old category no longer apply — review and re-pick your tags after changing it.

Tune a noisy or quiet channel ​

If a channel is showing too much or too little, edit it rather than deleting it. Remember that tags pick out specific things in the category and scope decides how those tags combine — see How scope and tags work together.

  • Too much? Add tags so the channel only includes updates about specific things, instead of the whole category. If it already has several tags, switch the scope to Narrow so updates must match all of them.
  • Too little? Remove some tags so the channel follows more of its category. If it has several tags, switch the scope to Broad so matching any one of them is enough.

Remove a channel ​

Removing a channel stops its updates from appearing in your Pulse feed. Open the channel and choose to delete it.

TIP

Deleting a channel only affects your feed — it doesn't change anything for anyone else, and it doesn't delete the underlying business data. You can always create the channel again later.
