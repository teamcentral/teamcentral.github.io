Tasks ​

Tasks are things you ask Corbi to do, described in plain language. Corbi turns your description into a draft you can review before it becomes live. This gives you a chance to check the work before it runs for real.

📷 Screenshot: Task details with live and draft sections — coming soon.

Creating a task ​

  1. Select Tasks in the navigation drawer.
  2. Choose to create a new task.
  3. In the input box ("What task do you want to create?"), describe the task in plain language and send it.

Corbi creates the task and opens its details page.

Describe the outcome, not the steps

Tell Corbi what you want to happen — "Email me a summary of new high-priority support tickets each morning" — and let it work out the steps. You'll review the result before anything goes live.

Draft and live versions ​

Every task has versions, and each version has a status:

StatusMeaning
DraftA proposed version you can review and refine. It isn't active yet.
LiveThe version that's currently active and running.

When you create or change a task, Corbi prepares a draft. You review the draft, and once you're happy with it, it becomes the live version. A task can have a live version, a draft, or both at once.

The task details page shows the current live version and the draft together, so you can compare what's running now with what's proposed.

Viewing a task's history ​

From a task's details page, open the menu (the ⋮ icon) and choose All Versions to see every version of the task. Each entry shows its status (Draft, Live, and so on), the prompt that created it, and the date it was created. Select any version to view its details.

Deleting a task ​

From a task's details page, open the ⋮ menu and choose Delete. You'll be asked to confirm.

Deleting is permanent

Deleting a task cannot be undone. If a task is just noisy or no longer needed temporarily, consider whether you really want to remove it before confirming.

Tasks vs. Chat ​

  • Use Chat for a back-and-forth conversation or a one-off question.
  • Use Tasks when you want Corbi to carry out something structured that you can review, keep, and revisit over time.
