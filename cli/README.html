Central CLI docs (VitePress) ​

Reference site for the central CLI. The /cli/ pages + sidebar are generated from the command model (central gen-docs), so they stay in lockstep with --help.

Develop ​

bash
npm install        # first time
npm run gen        # regenerate ./cli from the CLI command tree (runs `central gen-docs`)
npm run dev        # VitePress dev server with local search

npm run build produces the static site; CI regenerates ./cli before building so the published manual is always current.

The contents of cli/ are generated. Edit command/option descriptions and examples in Central.Platform.Cli (they drive both --help and these pages), not the markdown here.
