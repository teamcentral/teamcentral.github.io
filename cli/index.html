CLI Reference

provision

Seed initial state into a freshly-provisioned customer environment (e.g. branding).

migrate

Copy a tenant's data between Cosmos (NoSQL API) and Mongo vCore in either direction.

config

Validate connector/endpoint config — files, a customer's live config, or a baseline diff as a regression gate.

verify

Read-back parity checks for a tenant against a live storage backend.
